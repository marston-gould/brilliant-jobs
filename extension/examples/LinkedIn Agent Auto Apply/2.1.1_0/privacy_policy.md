# Privacy Policy for LinkedIn Agent Auto Apply

Last Updated: [Current Date]

## Introduction
This Privacy Policy explains how the LinkedIn Agent Auto Apply Chrome extension ("we", "our", or "the extension") collects, uses, and protects your information when you use our service.

## Information We Collect

### Automatically Collected Information
- Browser type and version
- URLs of LinkedIn job pages you visit
- Interaction data with job application forms
- Extension usage statistics

### User-Provided Information
- Profile information used for job applications
- Resume and application preferences
- Job search preferences and criteria

## How We Use Your Information
We use the collected information for:
1. Automating job application processes
2. Filling application forms accurately
3. Saving your application preferences
4. Improving the extension's functionality
5. Providing technical support

## Data Storage
- All personal information is stored locally in your browser using Chrome's storage API
- No personal data is transmitted to our servers except when explicitly connecting to CareerGPT services
- Form data is only used during the active application process

## Third-Party Services
We interact with:
- LinkedIn.com for job applications
- CareerGPT.io for enhanced functionality
- No data is shared with any other third parties

## Data Security
We implement security measures including:
- Local storage encryption
- Secure communication protocols
- No permanent storage of sensitive information

## Your Rights
You have the right to:
- Access your stored information
- Delete your data
- Disable the extension at any time
- Clear all stored data through Chrome's extension settings

## Changes to Job Sites
- The extension adapts to LinkedIn's interface
- Updates may be required when LinkedIn changes their website
- We strive to maintain compatibility and security

## Updates to Privacy Policy
We may update this privacy policy. Users will be notified of any significant changes.

## Data Deletion
To delete your data:
1. Right-click the extension icon
2. Select "Options"
3. Click "Clear Data"
4. Uninstall the extension to remove all local data
